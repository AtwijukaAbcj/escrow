# TrustPay Africa

A starter monorepo for TrustPay Africa: a digital escrow and trust infrastructure MVP with a backend API and a React web frontend.

## Structure

- `backend/` — Express + TypeScript API server
- `frontend/` — Vite + React web application

## Quick start

1. `npm install`
2. `npm run dev:backend`
3. `npm run dev:frontend`

Open the frontend at `http://localhost:5173` and the backend API at `http://localhost:4000`.

## Features included

- Transaction escrow workflow
- Digital contract and KYC scaffolding
- API-first architecture with sample endpoints
- Web UI for creating transactions, KYC, and releasing funds
