How it works

Simple for both sides.

A shared transaction workflow reduces uncertainty and gives each party a clear next action from agreement through final release.

01 · AGREE

Set the transaction terms

Create the transaction, identify the parties, define requirements and establish the conditions that govern payment.

02 · DELIVER

Fund and complete the work

The buyer funds the transaction while the seller completes the agreed delivery, service or project milestones.

03 · RELEASE

Verify and release funds

Completion is reviewed and approved before protected funds are released according to the transaction terms.
