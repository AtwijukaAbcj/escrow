Setup

  1. Start the Django server from the project folder with python manage.py runserver 0.0.0.0:8000.
  2. Use the login flow to obtain a JWT pair from /auth/login/.
  3. Attach the access token to the Authorization: Bearer ... header for protected requests.
  4. Use the refresh endpoint when the access token expires, then continue with the same workflow.

Hosted checkout

Create an API key with the checkout.write scope, create a session for a funding-ready transaction, and send the returned checkout_url to the customer or open it in an iframe.

POST /api/v1/checkout/sessions/
Authorization: Api-Key tp_your_secret_key
Content-Type: application/json

{
    "transaction_id": "your-transaction-id",
    "external_reference": "ORDER-1042",
    "buyer_name": "Amina Buyer",
    "buyer_email": "amina@example.com",
    "success_url": "https://merchant.example/paid"
}
