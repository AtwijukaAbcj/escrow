Setup

  1. Start the Django server from the project folder with python manage.py runserver 0.0.0.0:8000.
  2. Use the login flow to obtain a JWT pair from /auth/login/.
  3. Attach the access token to the Authorization: Bearer ... header for protected requests.
  4. Use the refresh endpoint when the access token expires, then continue with the same workflow.

Hosted checkout

Create an API key with the checkout.write scope, then send the complete cart order when the customer chooses TrustPay. TrustPay creates one order-level escrow transaction and one hosted session at that moment. Reuse the same order_id when a customer retries payment.

POST /api/v1/checkout/sessions/
Authorization: Api-Key tp_your_secret_key
Content-Type: application/json

Embed checkout on a website

Keep the API key on your merchant server. Your server sends the completed cart only when the customer clicks Pay, receives the hosted checkout_url, and returns that URL to the browser. Send a unique Idempotency-Key header so network retries reuse the same checkout session.

<button id="pay-with-escrow" type="button">Pay securely with TrustPay</button>

<dialog id="trustpay-checkout">
    <button id="close-checkout" type="button">Close</button>
    <iframe
        id="trustpay-frame"
        title="TrustPay secure checkout"
        width="100%"
        height="720"
        loading="lazy"
        allow="payment *"></iframe>
</dialog>

<script>
    const dialog = document.querySelector('#trustpay-checkout');
    const frame = document.querySelector('#trustpay-frame');

    document.querySelector('#pay-with-escrow').addEventListener('click', async () => {
        // Your server calls POST /api/v1/checkout/sessions/ with Api-Key auth.
        const response = await fetch('/api/create-trustpay-session', { method: 'POST' });
        const session = await response.json();
        frame.src = session.checkout_url;
        dialog.showModal();
    });

    document.querySelector('#close-checkout').addEventListener('click', () => {
        dialog.close();
        frame.src = '';
    });
</script>

Never put the Api-Key value in browser JavaScript. Use your server endpoint to create the session, then listen for the merchant return URL or payment webhook. Webhooks include X-TrustPay-Timestamp and X-TrustPay-Signature; verify the HMAC-SHA256 signature using the dedicated webhook secret shown once when the key is created. The iframe emits trustpay.checkout.payment_submitted, but use the signed webhook as the server-side source of truth.
